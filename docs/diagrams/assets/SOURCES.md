# Nguồn logo dùng trong sơ đồ ChatApp

Logo được dùng để nhận diện các công cụ trong bài thuyết trình. Không tạo lại bằng AI. Tất cả ảnh được nhúng trực tiếp vào file Draw.io bằng data URI; các file bên cạnh phục vụ việc tái tạo sơ đồ.

Devicon: https://github.com/devicons/devicon (MIT; tên và nhãn hiệu thuộc chủ sở hữu tương ứng). Hangfire dùng phần biểu tượng H tách từ logo chính thức. Các file `*-mark.svg` cắt khoảng trống quanh logo bằng viewBox để hiển thị rõ ở kích thước nhỏ. PITR là kỹ thuật phục hồi PostgreSQL, nên dùng logo PostgreSQL kèm nhãn PITR; không trình bày PITR như một sản phẩm độc lập. Các ảnh tham khảo không thay đổi kiến trúc hay cài thêm thư viện vào ứng dụng.
